Stock Learning

A Comprehensive Financial Analysis Platform

Powerful Streamlit-based web application for stock analysis, portfolio construction, and Syariah compliance screening with multi-language and multi-currency support.

View on GitHub Get Started

Key Features

Stock Overview

Visualize stock prices, general information, and fundamentals for any ticker. Supports global stocks and Indonesian Stock Exchange (IDX).

Syariah Stock Screening

Check Syariah (Sharia) compliance for stocks using OJK/HISSA-like criteria with localized criteria and sector/industry translation.

Portfolio Analysis

Build and analyze custom portfolios with various construction methods including Min-Var, Max Sharpe, Black-Litterman, ERC, and HRP.

Multi-Language Support

Full UI, static, and dynamic content translation in English and Bahasa Indonesia for comprehensive localization.

Multi-Currency

Display monetary values in stock's native currency with optional conversion to user-selected currency (USD/IDR) using live rates.

Responsive Design

Clean, responsive Streamlit interface that works seamlessly across desktop and mobile devices.

Getting Started

1

Clone the Repository

git clone https://github.com/mhmmdgoldy/stock_learning.git
2

Install Dependencies

pip install -r requirements.txt
3

Run the Application

streamlit run app.py
4

Access the App

Open your browser and navigate to http://localhost:8501

Requirements

  • Python 3.7 or higher
  • Internet connection for fetching stock data
  • No API keys required for basic features

About the Project

Stock Learning is a comprehensive financial analysis platform designed to make stock analysis accessible to everyone. Whether you're a beginner investor or an experienced trader, this application provides the tools you need to make informed investment decisions.

The platform integrates multiple data sources and analysis methods to provide a complete view of stocks and portfolios. With built-in Syariah compliance screening, it serves the needs of Islamic finance practitioners and investors seeking halal investment options.
